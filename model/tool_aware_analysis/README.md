# A0509 Tool Aware 동역학 궤적 분석

`model/.venv/Scripts/python.exe -m model.analyze_tool_aware`로 재생성한다. 입력은 기존 MuJoCo AG145 T1~T14 기록과 mDPG `box_approx` T1 기록이다. ROS 노드를 시작하거나 실로봇에 명령을 보내지 않는다.

## 비교 방법

- 각 AG145 trial에서 기록한 **동일한** `q`, `dq`를 bare A0509, AG145, mDPG 세 MuJoCo 모델에 적용한다. `ddq`는 모든 trial의 속도 이력에 동일한 중심 5점 선형 기울기를 적용해 다시 계산한다. 시뮬레이션 시각 중복은 마지막 행을 남기고 합친다. 시작 직후 정착 과도 현상 0.5초를 제외하고 나머지 유효 행을 모두 사용한다. 이 제외 구간은 `--warmup-seconds`로 바꿀 수 있다.
- 각 모델의 `qfrc_inverse`를 계산하고 bare A0509와의 차이를 구한다. 같은 자세에서 `dq=ddq=0`으로 계산한 역동역학 차이가 **정적 하중 효과**다. 전체 차이에서 이를 뺀 값이 **동적 효과**다. 이는 실측 모터 토크가 아니라 MuJoCo 일반화 역동역학 토크다.
- MuJoCo 장면 질량 합계는 bare 18.824 kg, AG145 20.124 kg, mDPG 19.444 kg이다. AG145 관성도 근사이며, mDPG의 0.62 kg 박스 관성, `0 0 0` 장착 자세, TCP는 검증되지 않았다. 장면 파일과 원본 CSV의 SHA-256은 `summary.json`에 보존한다.
- AG145 기록의 동일 모델 역동역학 재계산 오차는 부동소수점 정밀도 수준(약 10⁻¹⁵ Nm)이다. mDPG 실제 T1 기록도 같은 수준으로 재생된다. 이는 **동일 모델 코드의 재현성** 검사이며 물리적 정확도 검증이 아니다.

나머지 T6~T12와 AG145의 수치는 `counterfactual_summary.csv`에 있다. mDPG 전체 차이는 대부분 정적 자세 하중이다. T1의 관절별 전체 차이는 J2 약 1.61 Nm, J3 약 2.54 Nm로 크지만, 공통 가속도 추정 이후 동적 차이는 각각 약 0.012 Nm와 0.005 Nm다. 따라서 현재 궤적은 **도구 장착에 따른 정적 하중**은 보여 주지만 **도구 관성 식별**에는 약한 신호를 준다.

T1의 실제 시뮬레이션 세 trial은 각각 1,001행이며, 관절 목표 추종 RMSE(6축·전체 행)는 bare 0.0183 rad, AG145 0.0184 rad, mDPG 0.0178 rad다. `/joint_states` 관찰 주기는 세 trial 모두 시뮬레이션 시각 기준 약 99.99 Hz이고 메타데이터의 추정 누락률은 0%다. 다만 기준 TCP가 각각 달라 이 세 추종 오차 차이를 그리퍼 성능의 인과 효과로 해석할 수 없다.

### 가속도 라벨 주의

예전 AG145 T1~T3 기록은 벽시계 차분 기반 `ddq`를 사용했고, T5~T14 및 최근 mDPG T1은 시뮬레이션 시각 속도 기울기를 사용한다. AG145 T1 기록의 `ddq` RMS는 2.38 rad/s²지만 공통 5점 추정에서는 약 0.08 rad/s²다. AG145 T2도 원본 5.45 rad/s² 대 공통 추정 약 0.20 rad/s²다. 이 차이 때문에 원본 토크 피크와 새 trial의 토크 피크를 그대로 순위화하지 않는다. 공통 추정도 하나의 필터 선택이며 독립 가속도 센서의 정답값이 아니다.

## Tool Aware 궤적 설계에 주는 의미

1. **정적 하중과 자세**: T13/T14처럼 다른 시작 자세가 정적 토크 차이를 바꾼다. J2/J3와 손목 자세를 넓히는 안전한 자세 세트가 도구 질량중심 식별에 필요하다.
2. **관성 가진**: 현재 동적 효과는 mDPG에서 최대 약 0.017 Nm RMS로 작다. 특정 관절의 가속도 크기·방향을 체계적으로 바꾸되 MuJoCo 경로 전체의 관절·충돌 제한을 먼저 검증하는 별도 궤적이 필요하다. T5~T14의 이름이나 원본 CSV 토크 피크만으로 관성 식별력을 주장할 수 없다.
3. **모델 학습**: mDPG 실제 시뮬레이션은 T1 한 trial뿐이다. T2~T14 mDPG 수치는 AG145 상태를 mDPG 모델에 넣은 **반사실 계산**이지 mDPG의 실행·추종 데이터가 아니다. Tool Aware PKAN의 독립 검증이나 실물 일반화 성능으로 사용하면 안 된다. 실제 장착 변환·질량중심·관성 및 반복 trial을 확보한 뒤 도구 조건 벡터를 정의해야 한다.

## 파일

- `summary.json`: 모델 질량, 입력 해시, 재생 검증과 한계
- `actual_T1_trials.csv`: 세 도구별 실제 T1 시뮬레이션 기록의 추종·품질
- `counterfactual_summary.csv`: T1~T14의 도구별 정적·동적 토크, 질량행렬 효과
- `per_joint_effects.csv`: 궤적·도구·관절별 효과
- `tool_effect_by_trajectory.png`, `T1_tool_torque_delta.png`, `T1_dynamic_delta.png`: 요약과 시간 이력 그래프
